## 教训 / 备忘

- PowerShell 5.1 读无 BOM UTF-8 脚本时个别汉字字节会撞引号 → 临时脚本用纯 ASCII 写
- exec_command 传内联 PowerShell 时 `$` 变量会被吞 → 一律写成 .ps1 脚本文件执行
- creating-forward 的 tests 用包根相对路径定位（Path(__file__).parents[1]），整体迁入子目录后无需改代码即可跑
- 原 agent-tool 的 ohmyagent 只认单文件 .md skill，不认目录+SKILL.md 格式 → 平铺兼容层 skills/*.md 正好是 ohmyagent 的安装源
