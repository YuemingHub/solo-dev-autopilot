# MingOS Phase 0：当前事实基线

## 目标

让任何新 Agent 不依赖旧对话，也能准确理解 MingOS 当前状态、边界、下一步和禁止事项。

## 成果

在 MingOS 仓库创建或更新：

```text
docs/development/
├── CURRENT_TRUTH.md
├── BRANCH_AND_PR_MAP.md
├── ACTIVE_PRODUCT_BASELINE.md
├── KNOWN_DEBT.md
└── AUTONOMY_BOUNDARIES.md
```

并初始化：

```text
.creating-forward/
├── state.yaml
├── events.jsonl
├── requirements.md
├── deliverables.md
├── decisions/
├── tasks/
├── evidence/
└── context-packs/
```

## 任务图

### P0-001 初始化协议工作区
依赖：无  
完成标准：
- `.creating-forward/` 存在。
- 状态字段完整。
- 不包含密钥、真实家庭数据和会话内容。
验证：
- 运行 workspace validator。

### P0-002 核实仓库首读入口
依赖：P0-001  
完成标准：
- README、AGENTS、运行手册、部署文档的引用逐项检查。
- 不存在、过时、相互冲突的入口被记录。
- 不通过猜测补齐缺失内容。
验证：
- 链接与文件存在性检查。
- 人工抽查引用关系。

### P0-003 建立分支与 PR 图谱
依赖：P0-001  
完成标准：
- 默认分支、production、活跃开发分支和开放 PR 被列出。
- 每个开放 PR 标记：继续、整合、替代、关闭建议、需要人判断。
- 明确生产代码当前对应提交。
验证：
- Git / GitHub 查询证据。
- 图谱与真实 refs 对照。

### P0-004 建立当前运行基线
依赖：P0-002  
完成标准：
- 本地启动、端口、构建、测试、部署入口以当前代码为准。
- 旧命令与历史说明被标记。
- 生产动作保持未授权。
验证：
- package.json 与运行手册交叉检查。
- 只运行本地安全命令。

### P0-005 建立产品实现基线
依赖：P0-002, P0-003  
完成标准：
- 区分已经运行的能力、实验能力、计划能力。
- 区分 Ming Foundation 上位标准与当前应用种子。
- 不把存在代码解释为真实有效或标准符合。
验证：
- 对齐文档与代码、测试交叉检查。

### P0-006 建立已知债务与风险
依赖：P0-003, P0-004, P0-005  
完成标准：
- 文档漂移、测试基线、开放 PR、历史密钥形状命中、部署风险等被记录。
- 每项有来源、影响、建议处理和是否阻塞。
验证：
- 不隐藏已有失败和未核实项。

### P0-007 建立自主开发授权边界
依赖：P0-006  
完成标准：
- 自动允许、需要暂停、绝不允许三类动作写清。
- 人类决策点控制在目标、伦理、高风险和主观验收。
验证：
- 与 adapter 和 state authorizationProfile 一致。

### P0-008 修复开发入口
依赖：P0-002 至 P0-007  
完成标准：
- 只修复事实入口和状态文档。
- 不改业务逻辑。
- 所有修改可逆。
验证：
- diff 范围审计。
- 文档链接和仓库边界测试。

### P0-009 独立验证
依赖：P0-008  
完成标准：
- Verifier 独立检查事实、diff、引用和证据。
- 给出 passed / failed / blocked。
- Builder 自述不作为证据。
验证：
- 独立验证记录落盘。

### P0-010 Draft PR 或补丁
依赖：P0-009  
完成标准：
- 仅在验证通过后生成。
- 默认 Draft。
- 不合并、不部署。
- PR 描述包含证据、边界、剩余风险。
验证：
- PR 状态或补丁文件存在。

### P0-011 中断恢复测试
依赖：P0-010  
完成标准：
- 新会话或新 Agent 只读取 `.creating-forward/` 与仓库即可准确续接。
- 不重复询问已确认事实。
验证：
- 恢复摘要与真实状态一致。

## Phase 0 完成定义

- 当前事实基线存在。
- 入口漂移已显式处理。
- 分支与 PR 状态可理解。
- 开发授权边界明确。
- 状态和事件可恢复。
- 没有产品功能改动。
- 没有生产动作。


## P0-012 首次运行复盘与候选提取

依赖：P0-011

完成标准：
- 填写运行复盘。
- 统计必要与不必要人工干预。
- 区分 MingOS 实现问题、Adapter 问题和 Core 协议问题。
- 只对可复现的通用问题创建协议候选。
- 不自动修改正式 Core 版本。

验证：
- 每个候选有关联 observation 与证据。
- 没有把单次项目问题直接提升为 Core 规则。
