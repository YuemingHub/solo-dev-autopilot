# 知行合伙人开发计划

## 目标

为普通用户构建一套可被 AI Agent 加载的“知行合伙人”工作协议：用户用自然语言提出想法，Agent 通过极简澄清理解需求，询问有人值守或无人值守模式，按任务步骤执行并在每一步验证后推进，最终交付成果、代做决定清单和人工最后一步清单。

## 当前决策

- 产品形态：可加载到 AI Agent 的工作规范/提示词/技能包
- 兼容策略：平台无关核心协议 + 各 Agent 适配层
- 首期载体候选：极简 Skill/规则包，MCP 暂不作为必需依赖
- 首期交付：可加载 Skill 包，包含核心提示、状态、任务循环、决策记录模板和软件创作示例
- 首发验证：软件产品创作类任务
- 用户模式：有人值守与无人值守
- 用户语言：“我在 / 你先做”
- 核心控制点：每一步执行后必须验证，验证通过才允许推进
- 无人值守策略：可代做则继续，必须用户完成则跳过并记录，用户回来后集中说明
- 之前关于 Web、服务端持久化和单用户模式的决策均降级为待重新评估项

## 待确认问题

- 首个 Agent 承载平台和加载方式
- Agent 是否具备文件、终端、浏览器和代码执行能力
- 协议是单一系统提示词、Skill、插件还是多文件 Agent 包
- 交付成果和状态如何持久化
- 无人值守模式的默认决策和安全边界
- “我在”切换时的恢复与强制核对规则
- 首个协议交付载体及适配格式
- 是否首期只做 Skill，还是同时提供 MCP 增强能力
