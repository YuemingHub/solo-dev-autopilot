# 成熟度模型

## L0 文本提示

只有提示词，没有稳定状态、证据和恢复。

## L1 可加载协议

具备 Skill、基础状态模板和安全边界。

## L2 可恢复执行

具备任务图、事件日志、检查点和中断恢复。

## L3 可验证执行

每项完成都有证据；独立 Verifier 可以复核。

## L4 受控多 Agent

总控、执行和验证角色能够并行、汇合并处理冲突。

## L5 真实项目自治

在 MingOS 等复杂项目中，用户只参与少量关键决定，系统可持续形成 Draft 成果。

## L6 跨 Agent 可移植

不同 Agent 环境对同一任务遵循相同核心契约，结果差异可解释。

## L7 受治理自我改进

系统能从真实失败形成协议候选改进，并通过测试、审查和版本治理成熟。

## 当前目标

`0.4.0-dev` 目标不是宣称达到 L7，而是形成可移植的通用 Core、可恢复状态契约和项目 Adapter 边界，并继续用真实运行验证从 L2 向 L5 推进。
