# 产品决策基线 v0.4.0-dev

本文档是对历史记录和当前协议的正式决策归并。出现冲突时，按以下优先级判断：

1. 用户最新明确决定。
2. 本决策基线。
3. 已批准的协议规范。
4. 历史 PRD 与发现记录。
5. 实现细节和旧工作台输出。

## C. 当前版本边界

### 当前开发版自动允许
- 读取仓库和规范。
- 初始化状态工作区。
- 使用合成数据。
- 在受控开发分支进行可逆修改。
- 运行本地测试和构建。
- 生成补丁或 Draft PR。
- 提出协议候选改进。

### 当前开发版必须暂停
- 生产部署与正式发布。
- 合并 PR。
- 真实家庭数据访问和迁移。
- 外部正式发送。
- 产生费用。
- 不可逆删除。
- 改变上位原则、核心目标和专业判断标准。
- 发布新的核心协议版本。

## D. 未来允许重新评估

- MCP 能力发现与统一工具层。
- 云端状态同步。
- 多用户协作。
- 受控自动部署。
- 协议市场或 Adapter 分发。
- Web 观测和复盘界面。
